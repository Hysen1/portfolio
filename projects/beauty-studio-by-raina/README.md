# Beauty Studio by Raina — portfolio demo

This project preserves the public-facing pages of the WordPress and Elementor website as a GitHub Pages demo.

Live demo: https://hysen1.github.io/portfolio/projects/beauty-studio-by-raina/

The demo includes the original layout, media, translated pages, and browser-side navigation. Booking and contact forms are labeled as demonstrations and do not submit information. WordPress administration and database features remain in the original private WordPress project.

The deployed files are static HTML, CSS, JavaScript, images, and fonts. They do not require the original Codespace to be running. No database exports, credentials, PHP source, or customer submission records are included.

The URL has no Codespaces idle timeout. It remains available while this repository and its GitHub Pages deployment are maintained.
